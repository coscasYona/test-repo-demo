# Marathon Shredding Program

A comprehensive 20-week program to go from running 30 minutes at 10.5 km/h to completing a full marathon — while getting shredded and maintaining strength.

## Athlete Profile

| Metric | Current |
|---|---|
| Running | 30 min @ 10.5 km/h (~5.25 km) |
| Bench Press | 45 kg |
| Squat | 130 kg |
| Deadlift | 180 kg |
| Goal | Run a full marathon (42.195 km) + get shredded |

## Key Principles

1. **Progressive overload** in running volume (~10% weekly increase max)
2. **Polarized training** — 80% easy runs, 20% hard efforts
3. **Concurrent training** — strategic strength work that supports running
4. **Moderate caloric deficit** — shred fat without torching muscle or running performance
5. **Periodized nutrition** — more carbs on hard/long days, lower carbs on easy/rest days
